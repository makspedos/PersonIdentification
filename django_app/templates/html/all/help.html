Help

1. Which image formats are supported?

Answer: JPG, PNG, and JPEG images are supported.

2. How can I run a prediction?

Answer: Upload an image or paste an image URL, then select at least one attribute.

3. How many faces can the app process?

Answer: The detector works best with one to five clearly visible faces.

4. What image size should I use?

Answer: Use images where visible faces are at least 224x224 pixels for better predictions.
