# Development Roadmap

## Application

- Improve the upload and result pages with clearer validation states.
- Add sample images that are safe to distribute with the repository.
- Add pagination and filtering for saved analysis results.
- Add password and account-flow coverage for edge cases.

## Machine Learning

- Export stable model artifacts for local inference.
- Add a reproducible model download or setup script.
- Add model-version metadata to saved predictions.
- Add an inference smoke test that runs when optional ML dependencies are installed.

## Deployment

- Add production settings documentation.
- Add static/media storage notes for cloud deployment.
- Add a lightweight CI workflow for checks and tests.
